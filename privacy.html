Privacy policy

Last updated: 28 October 2026

What this application is

A personal, single-user OAuth client for rclone, an open-source command-line file-sync tool. It runs only on its owner's own computers and accesses only its owner's own Google Drive.

Who uses it

One person: the owner of the Google account that authorises it. The application is not published to, offered to, or usable by anyone else.

What data it accesses

With the owner's explicit consent, it uses the Google Drive API to read and write files in the owner's own Google Drive. It does this solely to copy files between the owner's computers and the owner's Drive.

What data is collected, stored or shared

None. The application has no server, no database, no analytics and no telemetry. Nothing is transmitted to the developer or to any third party. OAuth tokens are stored only in the owner's local rclone configuration file on the owner's own machines. File contents pass directly between the owner's machine and Google's servers.

Data retention and deletion

Because no data is collected, there is nothing retained to delete. Access can be withdrawn at any time from the Google Account permissions page, which immediately and permanently revokes the application's access.

Changes

Any change to this policy will be published on this page with an updated date.
